Privacy Policy

Newport LPS Payment extension
Effective date: 9 October 2026

Newport LPS Payment is a browser extension for hotel front-desk staff. It signs an operator in to a Newport backend chosen by the property, keeps that session on the workstation, and shows the LPS payment dialog on the property’s OPERA page.

The extension sends data only to the Backend URL and Admin UI URL that an administrator saves in Options. It does not send data to an analytics service, an advertising network, or any other third party.

Information the extension handles

  • Sign-in details. When you sign in, the extension sends your username, organisation code, and a hash of your password to the configured Backend URL. It does not store the password.
  • Session. After a successful sign-in, the extension stores the session token, username, and menu permissions returned by that backend. It prefers browser session storage and uses local extension storage only if session storage is unavailable. Logging out, or saving a change in Options, deletes the session.
  • Property settings. Options stores the organisation code, Backend URL, Admin UI URL, OPERA hostname, and the language you choose (English or Filipino). These stay on this browser until an administrator changes them or you remove the extension.
  • Workstation status. The backend may report a workstation number and whether this PC is bound to a workstation. The extension shows that status. It does not read the computer’s IP address.
  • Payment dialog. The extension opens the payment page from the configured backend inside a frame on the OPERA tab, and passes the session token so that page can load. Card numbers and other payment details entered in that page are handled by the Newport backend. The extension does not read, store, or transmit them.

How that information is used

  • To authenticate the operator and keep the payment connection open.
  • To show or hide the payment dialog on tabs whose host matches the configured OPERA hostname.
  • To open the Admin UI. If you are signed in, the session token, username, and menu list are placed in the page address hash so the Admin UI can continue the same session. The hash is not sent to the network as a query string.
  • To remember the language of the extension’s own login and options pages.

The extension does not use this information for advertising, to build a profile for unrelated products, or to assess creditworthiness. It does not sell personal information.

Browser permissions

  • Storage holds the settings and session described above.
  • Alarms wake the extension so the payment connection stays open. This does not collect information.
  • Tabs is used to find OPERA tabs for the configured host and to open the Admin UI. The extension does not read browsing history or the contents of other pages.
  • Site access includes the OPERA host used for the payment overlay, and local or HTTPS addresses so the property can point the extension at its own Newport backend and Admin UI. The extension contacts only the URLs saved in Options. It does not read other websites.

Where data is stored and how long it is kept

Settings and the session stay in this browser’s extension storage. They are not copied to a GreenCloud server by the extension itself. The Newport backend you connect to stores and retains account and payment records under that system’s own policy.

The session remains until you log out, until Options are saved, or until the browser clears session storage. Settings remain until they are changed or the extension is removed. Removing the extension deletes the data it stored in the browser.

Who can see it

People who use this workstation can see the signed-in username and connection status in the extension. Administrators of the configured Newport backend and Admin UI can see the account and payment activity those systems record. Use HTTPS for the Backend URL and Admin UI URL except when you are testing on this computer.

Children

The extension is a workplace tool for hotel staff. It is not directed at children.

Changes

If this policy changes, the effective date at the top of this page will be updated. Continued use of the extension after that date means the updated policy applies.
